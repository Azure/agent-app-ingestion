# Contributing

Create your working branch from `develop` and open contribution pull requests
against `develop`. Only release branches named exactly `release/X.Y.Z` in this
repository may open pull requests against `main`.

Describe the change briefly, include relevant test results, and update
documentation when behavior changes. The quality gate runs automatically on
pull requests and must pass before merge. These checks support manual review;
they do not replace it.

## Code of Conduct and CLA

This project follows the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).
See its [FAQ](https://opensource.microsoft.com/codeofconduct/faq/) or contact
[opencode@microsoft.com](mailto:opencode@microsoft.com) with questions.

Most contributions require a [Contributor License Agreement (CLA)](https://cla.opensource.microsoft.com/).
The CLA bot will guide you through any required steps when you open a pull request.
